이미지를 바꾸는 가장 쉬운 방법

1. 이 my-images 폴더에 PNG 파일을 넣습니다.
2. 아래 파일 이름 규칙만 맞추면 됩니다. 코드를 수정할 필요가 없습니다.

01-profile.webp = 1번 캐릭터 대표 이미지
01-1.webp ~ 01-5.webp = 1번 캐릭터 상세 이미지 5장
02-profile.webp = 2번 캐릭터 대표 이미지
02-1.webp ~ 02-5.webp = 2번 캐릭터 상세 이미지 5장

이 방식으로 10번까지 반복하세요.
예: 10-profile.png, 10-1.png, 10-2.png, 10-3.png, 10-4.png, 10-5.webp

파일을 넣지 않은 자리는 기본 이미지가 표시됩니다.
PNG 형식으로 저장하고 정확히 같은 파일명을 사용하세요.
